# Number Garden Memory

- The game is designed for people with dementia, so pacing is untimed by default and feedback is warm rather than punitive.
- Session details are stored locally in the browser under `number-garden-history`; no backend or personally identifying data is collected.
- A `?demo` flag starts the first mixed round and selects the correct answer automatically, making visual verification deterministic.
- The generated reference image is intentionally used as a subtle visual texture in the main play shell; the mascot PNG is used as the robin guide.
